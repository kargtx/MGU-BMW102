# 🟦🟦 BMW102 · Стробоскопы 🟥

**Мигание дальним светом и световое шоу с головного устройства (МГУ).** ID7 и ID8.
Без адаптера и без движка: команды шлёт сама МГУ через свой диагностический транспорт TASU,
так же как G-xDrive 0.2.0.

> ⚠️ **Только частная территория и только на стоянке.** Мигание фарами, похожее на спецсигналы,
> на дорогах общего пользования запрещено. Приложение само не работает при скорости выше 3 км/ч.

## Как это работает

При открытии приложение **только читает** блоки и выбирает путь к фарам — первый, что ответит:

| Путь | Блок | Команда | Где |
|---|---|---|---|
| Функции света | BDC `0x40` | `2E D542 <функция> <время×10 мс>` — вспышка, блок сам гасит её | большинство G (BDC, BDC_G11, BDC_G05) |
| LED-каналы фар | FLM01 / FLE `0x43`, `0x44` | `31 01 3000 <ток> <ШИМ>` на каждый канал | адаптивные LED-фары |
| Цифровые выходы | BDC `0x40` | `2F 4501 03 <выход> 01/00` (BDC_G05: `2F E3B5`) | фары на выходах BDC |

Световое шоу на BDC_G11/BDC_G05 — встроенный режим блока `2E 4530`, на LED-фарах — все каналы против темноты.

**Режим «Полиция»** — серии вспышек дальнего то слева, то справа: одна фара удерживается на своём
обычном свете, пока мигает другая. Для фар FLE каналы дальнего сначала надо **обучить**: кнопка
«Обучить дальний свет», затем включить дальний подрулевым рычагом (15 с).

## Защита

- Только при скорости ≤ 3 км/ч (Vehicle2 `statusCarSpeed2`); тронулись — остановка на следующей вспышке.
- Запуск — двойным нажатием в течение 6 с.
- Не дольше 30 с за нажатие, затем отдых не меньше, чем длилась работа (минимум 10 с);
  не больше 2 мин мигания за 10 мин.
- LED-фары: ток не выше, чем в кодировке машины (по её тесту ламп), только существующие каналы;
  остановка при температуре LED FLM01 ≥ 90 °C.
- Вспышка BDC ≤ 150 мс и гаснет сама; диагностическая сессия падает сама через несколько секунд
  без запросов — если приложение упадёт, фары вернутся машине.
- При остановке и закрытии приложение возвращает выходы машине (`2F … 00`, `31 02 3000`, `10 01`).

## Установка

Как у «Контактов» — без движка (`mgu-python` не нужен).

- **GitHub:** Store → Источники → этот репозиторий, ветка `main` → **BMW102 · Стробоскопы** → Install.
- **USB:** собрать папку флешки (Node 18+):
  ```powershell
  node ..\mgu-store\deploy\mgu-install.js usb-repo E:\ .
  ```
  Store → **USB** → **BMW102 · Стробоскопы** → Install.

Журнал: `journalctl | grep bmw102_strobe` (каждый шаг, найденный путь, причина остановки).
