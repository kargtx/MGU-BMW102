# BMW102 G-xDrive — изменения

## 0.2.0
- Команды идут через собственный диагностический транспорт МГУ — TASU
  (SOME/IP InternalTasu), как у приложений idrive7-apps; HSFZ-шлюз не нужен.
- Путь выбирается по индексу блока (22 F1 50): DSC 0x29 (2E DB E1 00) или,
  на G05 и др. с IB по 0x29, VIP 0x39 (2E DB 2F 00); NRC 7E/7F -> 10 03 и повтор.
  Логика и адреса — из проверенного live_adjustments (idrive7-apps).
- «Отключить xDrive» — двойным нажатием в течение 6 с.

## 0.1.2
- Запуск по образцу приложений Store: полный SOME/IP-манифест платформы
  (закладки, WakeUpOnDemand, Provisioning, Vehicle и др. — без них старт
  зависал на «Загрузке приложения»), статус видимости менеджеру
  (registerHmiVisible), корректный выход по shutdown, экран ST_OnlineApps_*.
- Шаги старта и нажатия пишутся в журнал движка (journalctl -u bmw102-xdrive).

## 0.1.1
- npm-shrinkwrap.json без зависимостей: менеджер приложений МГУ больше не
  пытается скачать oap-sdk из npm (он уже вшит в собранный app.js).

## 0.1.0
- Первая версия: плитка в меню МГУ, одна кнопка отключения полного привода
  на G-кузове. МГУ отправляет UDS `2E DB E1 00` в раздатку (VTG 0x29) по HSFZ
  через root-демон (без ELM327/Bluetooth). Кнопка «Проверить связь» (probe)
  ничего не меняет. Только G-кузов.
