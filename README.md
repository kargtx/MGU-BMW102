# 🟦🟦 G-xDrive · BMW102 🟥

**Отключение полного привода (xDrive → 100% задний) прямо с головного устройства (МГУ).**
Только **G-кузов** (CLAR). Без ELM327, без Bluetooth-адаптера — команду шлёт сама МГУ через свой
диагностический транспорт TASU (как приложения idrive7-apps). Путь выбирается по блоку:
DSC 0x29 (`2E DB E1 00`) или, на G05 и др., VIP 0x39 (`2E DB 2F 00`).

```
  ┌─ плитка в меню авто ─┐        ┌─ root-сервис на МГУ ─┐        ┌─ раздатка ─┐
  │   «Отключить xDrive» │  unix  │  bmw102-xdrive       │  HSFZ  │  VTG 0x29  │
  │   (OAP-приложение)   │ ─────▶ │  (Python + hsfz.py)  │ ─────▶ │  2E DBE1 00│
  └──────────────────────┘ сокет  └──────────────────────┘        └────────────┘
```

Логика команды — та же, что в проверенном sxDrive: запись `2E DB E1 00`
(WriteDataByIdentifier, DID `0xDBE1` = 00) в раздатку. Успех — положительный
ответ `6E DB E1`. Привод возвращается сам после перезапуска авто.


> В этом же источнике Store есть вторая плитка — **BMW102 · Контакты** (папка [`contacts/`](contacts/README.md)):
> ремонт и обслуживание +7 965 925 6666 (@BMW102UFA), техподдержка приложений — Telegram @KARGTX.
>
> Ещё плитка — **BMW102 · Flash** ([`flash/`](flash/README.md)): стробоскоп дальним светом и световое шоу
> через TASU, экран как у Ambient config, запуск и остановка рычагом дальнего.

## Почему так

OAP-приложение в меню работает в песочнице (SOME/IP) и само не может слать
сырые диагностические кадры. Поэтому работа разделена:

- **Движок** (`engine/`) — root-сервис на самой МГУ. Открывает сокет к
  внутреннему диагностическому шлюзу и шлёт UDS в раздатку по **HSFZ**
  (переиспользуется проверенный `hsfz.py` из `idrive7-8-ssh-root`).
- **Плитка** (`app/`) — OAP-приложение «Отключить xDrive» в меню авто.
  По нажатию стучится в движок по unix-сокету `/dev/shm/bmw102-xdrive/xdrive.sock`
  (ровно как Store общается с mgu-updater) и показывает результат.

## Установка с USB-флешки (без интернета и без ноутбука в машине)

Готовая флешка лежит рядом с проектом: папка **`USB-флешка-G-xDrive`**
(и архив `USB-флешка-G-xDrive.zip`).

1. Флешка FAT32 или exFAT. Скопируйте **содержимое** папки в корень флешки,
   чтобы получилось `E:\mgu-repo\g-xdrive\mgu-repo.json`.
2. Вставьте флешку в USB машины (МГУ с установленным Магазином).
3. Store → **USB** → источник `…/mgu-repo/g-xdrive`.
4. **BMW102 · Отключение xDrive** → **Install**. Движок `G-xDrive · движок`
   поставится сам (его требует плитка), Python — тоже, если его ещё нет.
5. Когда Store попросит, перезагрузите МГУ (крутилка громкости 20–30 c).

Store пишет «Нет USB-накопителя», а медиа флешку видит? С ноутбука (Wi-Fi машины, флешка вставлена):
```powershell
powershell -ExecutionPolicy Bypass -File install\usb-diagnose.ps1 -Identity $HOME\.ssh\mgu_root_key        # что не так
powershell -ExecutionPolicy Bypass -File install\usb-diagnose.ps1 -Identity $HOME\.ssh\mgu_root_key -Fix   # исправить
```
Скрипт покажет, куда МГУ смонтировала флешку и где на ней `mgu-repo.json`. С `-Fix` он добавит
папку монтирования в `usb_roots` Магазина (настройка сохранится после обновлений).

Обновить флешку после правок (на компьютере, Node 18+):
```powershell
node ..\mgu-store\deploy\mgu-install.js usb-repo E:\ .
```

## Установка из GitHub (через интернет машины)

Репозиторий с этой папкой в корне (`mgu-repo.json` наверху) — источник для Store.

1. Store → **Настройки** → Wi-Fi: подключите раздачу телефона.
2. Store → **Настройки** → **Источники** → **Добавить источник** → `владелец/репозиторий`.
3. Выберите ветку **main**. Store читает её как repo tree и собирает плитку на МГУ.
4. **BMW102 · Отключение xDrive** → **Install** (движок встанет сам).

Приватный репозиторий: войдите в Store через **Sign in with GitHub** или добавьте токен.
Каждый новый коммит в `main` Store покажет как обновление.

## Установка по сети (SSH)

Нужно: root-SSH на МГУ (ключ `mgu_root_key`, см. корневой РОАДМАП, фазы 2),
установленный Магазин (`mgu-store`) и его **Python** (`mgu-python`).

### 1. Движок (root-сервис)

Windows:
```powershell
powershell -ExecutionPolicy Bypass -File install\install.ps1 -Identity $HOME\.ssh\mgu_root_key
```
macOS / Linux:
```sh
sh install/install.sh --identity ~/.ssh/mgu_root_key
```
Скрипт кладёт движок в `/var/opt/bmw102-xdrive/current`, ставит и запускает
systemd-юнит `bmw102-xdrive.service` (rootfs временно перемонтируется rw).
По умолчанию адрес МГУ `172.16.222.97` (Wi-Fi-хотспот); другой — `--host`/`-HostAddr`.

### 2. Плитка в меню (через Магазин)

Папка/репозиторий — это источник Магазина (есть `mgu-repo.json` с обоими
компонентами). В Store:

1. **Settings → Sources → Add source** → укажите GitHub-репозиторий с этой папкой
   (или подключите как USB-источник).
2. Установите **G-xDrive (движок)** и **Отключение xDrive** (плитку).
3. Перезагрузите МГУ (долгое нажатие крутилки громкости 20–30 c).
4. В меню приложений появится плитка **«Отключение xDrive»**.

> Движок можно поставить и через Магазин (пункт 2), и напрямую по SSH (пункт 1) —
> это один и тот же компонент `bmw102-xdrive`.

## Как пользоваться

В машине (G-кузов):

1. Зажигание в **режим диагностики**: 3 нажатия Start **без тормоза**
   (иначе раздатка ответит `NRC 0x22 ConditionsNotCorrect`).
2. Откройте плитку **«Отключение xDrive»**.
3. (необязательно) **«Проверить связь»** — безопасный опрос раздатки, ничего не меняет.
4. **«Отключить xDrive»** → строка результата покажет `✓ Полный привод ОТКЛЮЧЁН`.

Полный привод вернётся сам после перезапуска авто.

### По SSH / вручную (без плитки)

```sh
/var/opt/mgu-python/current/bin/python3 /var/opt/bmw102-xdrive/current/run_daemon.py  # сервис
# в другом окне:
python3 -m engine.cli probe      # проверить связь
python3 -m engine.cli disable    # отключить привод
```

## ⚠️ Проверка перед боем (важно)

Два момента зависят от конкретной машины и проверяются один раз командой `probe`
(она ничего не записывает):

1. **Адрес диаг-шлюза, видимый с МГУ.** Движок перебирает кандидатов
   (`engine/daemon.py → GATEWAY_CANDIDATES`). Если `probe` пишет «шлюз не найден» —
   задайте адрес вручную: в юните добавьте `Environment=XDRIVE_GATEWAY=<ip>`
   или добавьте адрес в список кандидатов.
2. **Адрес раздатки.** Для G используется `VTG 0x29` (как в sxDrive). `probe`
   подтверждает, что раздатка по этому адресу отвечает.

Если `probe` вернул `✓` — `disable` пойдёт тем же маршрутом.

## Удаление

```sh
ssh root@МГУ 'systemctl disable --now bmw102-xdrive.service; \
  mount -o remount,rw /; rm -f /etc/systemd/system/bmw102-xdrive.service; \
  mount -o remount,ro /; rm -rf /var/opt/bmw102-xdrive'
```
Плитку — через Магазин (Installed → Отключение xDrive → Remove).
